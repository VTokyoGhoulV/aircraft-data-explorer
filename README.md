# Aircraft Data Explorer

Консольная программа для поиска самолётов над выбранной страной. Получает границы территории через Nominatim, запрашивает данные OpenSky и сохраняет отобранные записи в JSON.

**Стек:** Python 3.14, requests, OpenSky Network API, Nominatim, pytest, Poetry.

## Возможности

- Поиск самолётов в географических границах выбранной территории.
- Фильтрация по стране регистрации и высоте.
- Сортировка по высоте и вывод заданного количества записей.
- Чтение, добавление и удаление записей в JSON-хранилище.

Данные представлены объектами `Aeroplane`. В классе также есть сортировка по скорости.

## Запуск

Нужны Python 3.14, Poetry и интернет. Выполняйте команды из корня проекта:

```powershell
git clone https://github.com/VTokyoGhoulV/aircraft-data-explorer.git
cd aircraft-data-explorer
poetry install --no-root
poetry run python main.py
```

Программа запросит четыре значения:

| Параметр | Пример |
| --- | --- |
| Страна, над которой искать самолёты | `Germany` |
| Максимальное количество записей | `5` |
| Страны регистрации самолётов | `Germany France` |
| Диапазон высот в метрах | `1000-12000` |

Страна поиска и страна регистрации могут различаться. Фильтр регистрации учитывает регистр и проверяет слова по отдельности: для примера выше достаточно совпадения с `Germany` или `France`.

Результаты выводятся в консоль и добавляются в `data/data.json`. Файл включён в репозиторий и должен существовать перед запуском.

Приложение обращается к OpenSky без авторизации. Если сервис ограничивает такие запросы или недоступен, получить данные не получится.

## Тесты

```powershell
poetry run pytest -q
poetry run pytest --cov=src
```

Тесты проверяют модель самолёта, API-адаптер, JSON-хранилище и консольный сценарий. Ответы внешних API подменяются.

## Ограничения

- Конструктор `Aeroplane` отклоняет нулевые координаты, скорость и высоту. Такие записи пропускаются, хотя нулевые значения могут быть корректными.
- Для HTTP-запросов не задан тайм-аут и не проверяется статус через `raise_for_status`.
- При некоторых ошибках API адаптер возвращает пустой словарь. Преобразователь ожидает ключ `states` и может завершить работу с `ValueError`.
- Поиск использует прямоугольные границы страны, а не её точный контур.
- При ошибке в количестве или диапазоне высот повторный ввод не предусмотрен.
- Повторное сохранение тех же самолётов добавляет дубликаты.
